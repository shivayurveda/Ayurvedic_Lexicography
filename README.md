# Ayurvedic Lexicography

This repository contains curated structured datasets derived from three classical Ayurvedic lexicographical sources used in the development of an ontology-based knowledge representation framework.

## Datasets

1. **Dhanvantari Nighaṇṭu**
2. **Rājanighaṇṭu**
3. **Bhāvaprakāśa Nighaṇṭu**

The datasets contain curated lexical, semantic, and attribute information used for ontology development and analysis of Ayurvedic materia medica.

## Data Sources

The datasets were prepared from the corresponding classical Ayurvedic Nighaṇṭu texts. The original textual sources are cited in the associated research article.
